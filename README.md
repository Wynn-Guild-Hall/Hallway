# Hallway

Public website for the unofficial Wynncraft Guild Hall — a cross-guild platform where representatives from major Wynncraft guilds can coordinate.

For more information, see **[hall.wynnvets.org](https://hall.wynnvets.org)**.

---

Currently hosted on Wynncraft Veterans infrastructure. To move: update `baseURL` in `hugo.toml` and the `proxy_pass` upstream in `nginx.conf`.
